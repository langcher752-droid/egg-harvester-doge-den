## 保留的功能

- 站点预览、搜索、勾选、仅导入选中项，≤30 条默认选中、>30 条默认不选。
- 站点卡片/列表布局及持久化、侧栏数字。
- 供应商版本路径规范化与浏览器 User-Agent。
- 原有站点、Key、文件、聊天和供应商操作；菜单复用这些操作，不替换业务实现。

## 本次调整

- Web 右下通知默认 7 秒、最少 6 秒；悬停和焦点暂停，可手动关闭。
- 原生通知 18 秒、悬停暂停；查看详情后从通知队列正确移除。
- 导航、站点、Key、聊天、文件、供应商及目录操作增加右键和更多菜单。
- 支持 Shift+F10、方向键、Escape；输入框与文本选择保留原生菜单。
- 次要操作只在桌面精确指针设备上折叠；悬停、键盘焦点或更多菜单可访问，触屏保留。
- Doge 加载态居中、放大至 96px，主要异步面板最低展示约 600ms；支持减少动画偏好。
- Safari 页面可见时每 60 秒检查一次，首次只建基线。新增条目显示非模态提示，点击查看才进入候选清单，不自动导入。
- Safari 文件不可读时静默降级，已见 URL 在配置数据库持久化，不重复提示。
